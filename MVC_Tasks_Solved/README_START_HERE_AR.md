# ASP.NET Core MVC — Task 4 + Task 5

كل مهمة في مجلد مستقل ومعها ملف README باللغة العربية يشرح التشغيل.

- `Task_4_Graduation/AcademyGraduation` — المهمة الرابعة بجميع مراحلها الثلاث (Session keys / Session List / EF Core relationships).
- `Task_5_Cafeteria/Part_1_Database_First` — المهمة الخامسة / Database First، قاعدة `CafeteriaDB` وسكربت SQL.
- `Task_5_Cafeteria/Part_2_Code_First` — المهمة الخامسة / Code First، قاعدة `CafeteriaEmployeesDB` وMigration جاهز.

البرامج صُممت بأسلوب بسيط للتعلّم والتعديل. كل مشروع يحتوي `.csproj` و `Program.cs` و Controllers و Models و Views والـ CSS.

**مهم قبل التشغيل:** استخدم .NET 8 وSQL Server LocalDB/SQL Server. يجب تحميل NuGet Packages في Visual Studio أول مرة. لا توجد ملفات `bin` أو `obj` داخل ZIP لأنها تُنشأ أثناء البناء.
